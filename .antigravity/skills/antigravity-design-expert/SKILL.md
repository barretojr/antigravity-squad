# Antigravity Design Expert

This skill contributes visual and interaction techniques for interfaces that benefit from spatial depth or motion-heavy presentation. It is a toolbox, not a mandatory aesthetic. Start with user goals, product identity, reference research, device constraints and accessibility. Use glassmorphism, 3D transforms, isometric layouts, GSAP, staggered entrances or parallax only when they improve comprehension or feedback; do not apply them to routine dashboards by default.

Build modular React components and preserve keyboard/focus semantics. Honor `prefers-reduced-motion`; keep feedback immediate, avoid animating expensive properties continuously, and measure before applying `will-change`. Prioritize responsive usability and legibility over decorative depth. Document the reason for each significant motion or spatial treatment in the Designer report.
